# Security Policy

## Supported Versions

The latest released version of this project receives security updates.

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please email the maintainer directly. Do not open a public GitHub issue for security-related problems.

We will respond to security reports within 7 days and provide a fix timeline.
